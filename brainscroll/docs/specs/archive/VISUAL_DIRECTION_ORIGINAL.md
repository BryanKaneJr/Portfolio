**BRAINSCROLL**

**VISUAL THEME & UI DIRECTION**

> A learning app that turns the pull of scrolling into visible knowledge progression - playful, brilliant, slightly game-like, and satisfying enough to become the better habit.

| **ADDICTING** | **BRILLIANT** | **LEARNING** | **LIGHT RPG** |
|---------------|---------------|--------------|---------------|

|  |  |
| --- | --- |
|  | Creative North Star<br>BrainScroll should look like knowledge is a video game resource. The learning is the product; levels, XP, mastery, titles and unlocks are the feedback system. |

**Duolingo clarity + mobile-game feedback + smart-internet energy**

## 1. Theme: Neon Academia

*Smart, energetic and modern - never medieval, corporate or school-textbook stiff.*

The visual system should use a deep, calm base with bright reward colors layered on top. Think midnight study room lit by a glowing screen: navy surfaces, electric violet, cool blue, mint and rare gold moments. The feeling of brilliance comes from light - subtle glow, illuminated progress, sparks, stars and crisp contrast.

|  |  |
| --- | --- |
| Where the RPG lives<br>Levels, ranks, skill trees, XP, mastery stars, titles, milestone nodes and unlock animations. | Where the RPG does NOT live<br>No swords, armor, medieval frames, treasure chests, fantasy parchment or combat UI. BrainScroll stays contemporary. |

|  |  |
| --- | --- |
|  | Duolingo-inspired, not Duolingo-copied<br>Borrow the clarity, friendliness, chunky rounded controls, immediate feedback and satisfying progress. Build an original brand palette, icon language and personality around BrainScroll. |

*Violet is the brand. Blue supports exploration. Mint means success. Gold is rare and valuable.*

## 3. UI Feel & Interaction Principles

*The app should feel alive before it ever feels complicated.*

- **Rounded and tactile.** Use chunky cards, generous corner radii, pill controls and obvious touch targets.

- **Fast hierarchy.** A user should know what to do within a second: continue, answer, level up, or review.

- **Motion with purpose.** Buttons depress; XP bursts; bars overshoot slightly and settle; unlocked nodes glow.

- **Reward progress, not screen time.** Scrolling alone should never look like achievement. Completion, recall and mastery create the dopamine hits.

- **Bright on dark.** Use luminous accent colors against deep surfaces so progress feels charged and valuable.

- **Adult-friendly playfulness.** Clever and energetic without looking childish or like classroom software.

## 5. The BrainScroll Learning Feed

*Use the familiarity of vertical scrolling, but give every scroll a destination.*

A level should feel like a compact learning encounter. The user swipes through a short sequence of cards - hook, explanation, connection, question, completion - rather than entering an endless feed.

| ROMAN HISTORY - LEVEL 18<br>One compact learning encounter |
| --- |
| HOOK “The Roman Empire did not actually disappear in 476.” |
| EXPLAIN Short visual + 2-3 lines of explanation. |
| CONNECT “Remember Constantine from Lv. 12?” |
| QUESTION Which half of the Roman Empire survived? |
| ANSWER Eastern ✓ |
| REWARD +24 XP · Roman History Lv. 18 → 19 |

|  |  |
| --- | --- |
|  | Behavioral goal<br>The interaction can scratch the same “one more swipe” itch as social media, but the unit ends decisively. BrainScroll should be satisfying because progress is visible - not because the feed never stops. |

*A hundred levels should feel like a journey - not a spreadsheet.*

Use a constellation-like path with glowing nodes, soft connecting lines and milestone clusters. Completed nodes are violet, current nodes pulse blue, mastered nodes become gold, and future nodes sit quietly in cool gray.

## 9. Guide Character & Personality

*A little Duolingo-like personality - without making a mascot the whole brand.*

|  |  |
| --- | --- |
| Brain Spark<br>A small floating intelligence orb / spark with simple eyes. It can react to streaks of correct answers, milestone unlocks and daily completion. | Voice<br>Clever, slightly irreverent, concise and adult-friendly. It celebrates progress and is comfortable telling the user to leave the app. |

- “Okay Einstein, calm down.” - after a strong run of answers.

- “That answer was aggressively wrong.” - playful incorrect feedback.

- “We’re done here. Go outside.” - after the daily quest is complete.

- Keep the jokes occasional. The guide should add personality, not interrupt every card.

## 10. Typography, Icons & Brand Mark

*Simple enough to disappear when learning starts; distinctive enough to be recognizable in the App Store.*

- **Typography.** Use a rounded modern sans-serif with a bold display weight for levels and milestones, paired with a highly readable regular weight for lesson content.

- **Numbers matter.** Level numbers, XP and percentages should be large, crisp and visually satisfying.

- **Icons.** Use simple filled or semi-filled icons with consistent stroke weight. Avoid overly detailed academic symbols.

- **App icon.** Dark rounded square with a violet/white BrainScroll mark - potentially a stylized “B” built from two stacked scroll cards or a simplified spark/brain + swipe trail.

- **Avoid.** Literal anatomical brains, graduation caps as the main logo, fantasy shields, parchment and generic “education blue.”

## 11. Microinteractions That Make It Feel Addictive

*Every important action should have a small, satisfying consequence.*

- **Correct answer.** Card snaps into a success state; mint pulse; tiny XP count-up.

- **Wrong answer.** Short coral reaction, then an explanation - no punitive hearts or lives.

- **Level completion.** Progress ring fills, subject level increments and the next node lights up.

- **Mastery.** Gold star appears with a slightly larger animation and richer sound.

- **Locked → unlocked.** Node transitions from gray to luminous violet/blue.

- **Daily complete.** Strong celebratory moment followed by a clean exit path rather than another engagement trap.

## 12. Design Rules to Protect the Concept

*The fastest way to lose the BrainScroll identity is to let the UI drift into generic education or generic mobile gaming.*

- Learning cards stay concise and visually breathable.

- The primary CTA on every screen is obvious.

- XP, levels and mastery must represent real completion or recall.

- No fake urgency, energy meters, loot boxes, gems or pay-to-win progression.

- Do not make every screen glow. Reward states should visually stand out from normal states.

- Use subject color accents carefully, but keep the BrainScroll violet/navy system dominant.

- Keep the app contemporary. The game layer should feel like a stat system, not cosplay.

**BRAINSCROLL DESIGN MANTRA**

> **Make learning feel like the thing the phone was supposed to be good at.**

**Scroll. Learn. Level. Leave smarter.**
